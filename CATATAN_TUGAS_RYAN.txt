B. TUGAS 1: MODUL GIS & PERSIMPANGAN (RYAN):
   1. Database Model (backend/app/models/intersection.py):
      - Tabel 'persimpangan': id_persimpangan, nama_lokasi, deskripsi,
        kode_simpang, latitude, longitude, aktif_loop_virtual, status_sensor.
      - Tabel 'jalur': id_jalur, id_persimpangan, arah (Utara, Selatan, Timur, Barat).
      - Tabel 'rutedarurat' & 'detail_rute': Relasi N-N rute darurat & urutan simpang.

   2. Logika Bisnis GIS (backend/app/services/gis_service.py):
      - Fitur 2 (Peta & Pemantauan):
        * Mengambil data peta real-time (traffic-density-map, intersection-status-list).
        * Fallback data default wireframe (Simpang A, B, C, D) jika database kosong.
        * Simpang C otomatis memicu alert kemacetan.
        * Indikator 'Sensor Offline' & pesan: "Data pemantauan tidak tersedia untuk beberapa simpang."
        * Tombol Refresh Data dengan respon: "Data lalu lintas berhasil dimuat ulang."
      - Fitur 3 (Kelola Sistem):
        * Validasi nama kosong -> HTTP 400 "Nama lokasi persimpangan wajib diisi!"
        * Sukses tambah persimpangan + otomatis 4 jalur (Utara, Selatan, Timur, Barat).
        * Pesan sukses: "Persimpangan baru berhasil ditambahkan!"
      - Fitur 4 (Rute Darurat Dijkstra):
        * Validasi tujuan kosong -> HTTP 400 "Lokasi tujuan wajib diisi!"
        * Menghitung rute optimal tercepat berbobot kemacetan dengan algoritma Dijkstra.
        * Simpan status 'Diajukan' dengan pesan: "Rute Darurat Optimal Ditemukan"
        * Aktivasi koridor hijau: update status 'Aktif', rekam waktu aktivasi,
          dan pesan: "Koridor hijau darurat berhasil diaktifkan!"

   3. Router API GIS (backend/app/routers/intersections.py):
      - GET  /api/intersections
      - POST /api/intersections/refresh
      - POST /api/intersections (Khusus Admin)
      - POST /api/intersections/emergency-route (Khusus Petugas)
      - POST /api/intersections/emergency-route/{id_rute}/activate (Khusus Petugas)

C. TUGAS 2: FITUR 1 (LOGIN & ROLE-BASED ACCESS CONTROL):
   1. Kredensial Akun Default Wajib (User Story 5.1):
      - Administrator : username: "admin_sinapsis"  | password: "adminSecure2026"
      - Petugas Lalin : username: "petugas_lalin01" | password: "petugasPass123"

   2. Aturan Respon Login (100% Persis Bab V):
      - Field kosong    -> "Login gagal. Semua field harus diisi!" (HTTP 400)
      - User tidak ada  -> "Login gagal. Akun tidak terdaftar." (HTTP 401)
      - Password salah  -> "Login gagal. Username atau password Anda salah." (HTTP 401)
      - Valid           -> "Login Berhasil!" (Token JWT disimpan & redirect ke /dashboard)

   3. Halaman Frontend UI yang Dibuat & Diperbarui:
      - frontend/login.html
        * Sesuai form SCR_AUTH_01 (Judul: SINAPSIS - SISTEM MANAJEMEN LAMPU LALU LINTAS CERDAS)
        * Sub-judul: LOGIN ADMINISTRATOR / PETUGAS
        * Masked password, submit button, dan area pesan error.
      - frontend/add-intersection.html
        * Form tambah simpang (Nama, Lat, Lng, Deskripsi, Checkbox Loop Virtual, Simpan, Batal).
        * Terproteksi khusus role Administrator.
      - frontend/emergency-route.html
        * Form rute darurat (Asal, Tujuan, Prioritas), visualisasi rute Dijkstra,
          dan tombol "Aktifkan Koridor Hijau".
        * Terproteksi khusus role Petugas Lalu Lintas.
      - frontend/dashboard.html
        * Ditambahkan class/ID: traffic-density-map, intersection-status-list,
          congestion-alert, dan tombol Refresh Data.
        * Navigasi RBAC otomatis menampilkan menu sesuai role yang sedang login.
