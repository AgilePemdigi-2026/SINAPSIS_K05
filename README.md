# legacy-neric

Arsip prototipe **NERIC** (Neuromorphic-Inspired Responsive Intersection Controller) dari lomba MSU iREX 2026.

Kode di folder ini **tidak dipakai** pada proyek kuliah SINAPSIS dan tidak lagi dirawat. Versi yang aktif ada di `../backend/`.
Folder dipertahankan sebagai referensi, terutama `NericDashboard/` (antarmuka React) yang mungkin dipakai ulang untuk frontend.

Kode asli sebelum perapian struktur juga tersimpan pada tag Git `legacy-neric-lomba`.
